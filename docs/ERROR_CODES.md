# Error Codes

code ทั้งหมดประกาศใน `pkg/apperr/*_errors.go` ผ่าน `apperr.New(...)` / `apperr.NewWithStatus(...)` — ประกาศซ้ำจะ panic ตอน boot

## รูปแบบ `abbcdd` (6 หลัก — แบบเดียวกับ askmelotto-api)

| ส่วน | ความหมาย | ค่า |
|---|---|---|
| `a` | กลุ่มตาม HTTP | `4` = client ทำผิด/ไม่มีสิทธิ์ · `5` = ระบบ/ภายนอกขัดข้อง |
| `bb` | module id | ดูตาราง module ด้านล่าง |
| `c` | ชนิด error | `1` validation · `2` authentication · `3` สถานะ/สิทธิ์ (ทำไม่ได้เพราะสถานะ) · `4` ไม่พบ/ซ้ำ · `5` DB · `6` service · `7` ระบบภายนอก · `8` storage |
| `dd` | ลำดับใน (module, ชนิด) | `01`–`99` |

ตัวอย่าง: `401201` = client (4) · module agent_auth (01) · authentication (2) · ลำดับ 01

## กฎ

1. จอง module id ในตารางด้านล่าง **ก่อน** ประกาศ error ของ module นั้น
2. ระบบใหม่นับ code ใหม่ทั้งหมด ไม่ใช้เลขของ `askmelotto_minigame-api`
3. code ที่ปล่อยไปแล้วห้ามเปลี่ยนความหมาย และห้ามนำเลขมาใช้ใหม่ (เลิกใช้ = ลบออก แต่เลขนั้นจองถาวร)
4. ข้อความ th/en ต้องอ่านรู้เรื่องสำหรับผู้ใช้ ห้ามมีรายละเอียดภายใน (ชื่อตาราง, SQL, stack)

| 403 | 200 | ไม่มีสิทธิ์ |
| 404 | 200 | ไม่พบข้อมูล |

| 503 | 503 | ระบบยังไม่พร้อม |
| 404001 | 404 | ไม่มี route นี้ |
