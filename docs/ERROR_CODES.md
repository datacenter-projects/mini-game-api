# Error Codes

code ทั้งหมดประกาศใน `pkg/apperr/*_errors.go` ผ่าน `apperr.New(...)` — ประกาศซ้ำจะ panic ตอน boot

## กฎ

1. จองช่วง code ของ module ในตารางนี้ **ก่อน** เขียน error ของ module นั้น
2. code ที่ frontend/provider ใช้อยู่แล้วในระบบเก่า ให้คงเลขเดิม — ต้องระบุไว้ใน spec ของ module ว่าคงเลขไหน
3. code ที่ปล่อยไปแล้วห้ามเปลี่ยนความหมาย และห้ามนำเลขมาใช้ใหม่ (เลิกใช้ = ลบออกจาก code แต่เลขนั้นถือว่าจองถาวร)
4. ข้อความ th/en ต้องเป็นข้อความที่ผู้ใช้อ่านรู้เรื่อง ห้ามใส่รายละเอียดภายใน (ชื่อตาราง, SQL, stack)

## Common (`pkg/apperr/common_errors.go`)

| Code | HTTP | ความหมาย |
|---|---|---|
| 200 | 200 | สำเร็จ |
| 400 | 200 | request อ่านไม่ได้ (body/query ผิดรูปแบบ) |
| 401 | 200 | ไม่ได้ login / token ไม่ถูกต้อง |
| 403 | 200 | ไม่มีสิทธิ์ |
| 404 | 200 | ไม่พบข้อมูล |
| 409 | 200 | ข้อมูลซ้ำ |
| 422 | 200 | ข้อมูลไม่ผ่าน validation |
| 429 | 429 | เรียกบ่อยเกินไป |
| 500 | 500 | error ภายในที่ไม่ได้ประกาศไว้ |
| 503 | 503 | ระบบยังไม่พร้อม |
| 404001 | 404 | ไม่มี route นี้ |
